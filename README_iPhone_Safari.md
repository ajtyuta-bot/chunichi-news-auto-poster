# 中日ニュース速報 — iPhone Safari対応版

これはSafariで開き、iPhoneの「ホーム画面に追加」でアプリ風に使うPWA対応版です。
**このZIPをダウンロードしただけでは、まだSafariで開ける公開URLはできません。** HTTPS対応のサーバーへ配置する必要があります。

## できること
- iPhone向け画面
- Safariホーム画面追加用メタデータ・アイコン
- RSS/Atomフィードを定期確認（初期設定5分ごと）
- キーワード「中日ドラゴンズ」を含む記事を検出
- 検出履歴と記事リンク表示
- サーバー側でX APIへ投稿する機能（初期状態OFF）
- 同じ記事URLの重複投稿防止

## iPhoneで使うまで
1. ZIPを展開
2. Node.js 20以上のサーバー環境にフォルダを配置
3. `npm install`
4. `.env.example` を `.env` にコピー
5. `.env` の `RSS_FEEDS` に利用条件を確認したRSS/Atom URLを設定
6. まず `AUTO_POST=false` のまま起動・検出テスト
7. HTTPSで公開（例：独自ドメインまたはホスティングサービスのHTTPS URL）
8. iPhoneのSafariで公開URLを開く
9. 共有ボタン →「ホーム画面に追加」→「追加」

## X自動投稿を有効にする場合
- X Developer Portalで投稿APIの利用資格・料金・制限を確認
- `.env` にX APIの認証情報をサーバー側だけに設定
- 検出テスト、誤検出、重複防止、投稿文を十分に確認
- 問題なければ `AUTO_POST=true` にしてサーバーを再起動

APIキーやアクセストークンをWeb画面・JavaScript・公開リポジトリに置かないでください。
ニュース媒体のRSS利用規約と見出し転載条件も必ず確認してください。

## 重要な制限
- iPhoneのSafariだけで常時バックグラウンド監視はできません。定期監視はサーバーで行います。
- こちらからホスティング契約・アカウント作成・公開はできていないため、公開URLはまだありません。
- X APIの費用・利用条件、各ニュースサイトのRSS提供状況は変更される場合があります。
