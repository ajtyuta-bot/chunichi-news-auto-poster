# 中日ニュース X自動投稿（スターター版）

中日ドラゴンズ関連のRSS/Atomフィードを定期チェックし、見出しや概要に `中日ドラゴンズ` が含まれる新着記事を検出するWebアプリです。iPhoneのSafariで開き、ホーム画面に追加するとアプリ風に利用できます。

## 大事な制約
- このZIPだけで公開済みアプリが完成・稼働するわけではありません。常時起動するサーバーへの配置とX API認証が必要です。
- iPhoneだけでバックグラウンド監視する方式ではありません。サーバーが定期チェックします。
- 初期設定は `AUTO_POST=false`（投稿OFF）です。まず検出だけでテストしてください。
- ニュースサイトのRSS利用条件を確認してください。フィードによっては商用利用・再配信・転載などが制限されています。利用条件に合うフィードだけ登録してください。
- 記事本文や写真をコピーせず、見出しと記事リンクを中心に投稿する設計です。見出しの転載可否も媒体の規約を確認してください。
- X APIの利用資格・料金・投稿制限は変更される場合があります。最新条件をX Developer Portalで確認してください。

## 起動方法（Node.js 20以上）
1. このZIPを展開する
2. ターミナルでこのフォルダに移動し `npm install`
3. `.env.example` を `.env` にコピー
4. `.env` の `RSS_FEEDS` を、利用条件を確認したRSS/AtomフィードURLに変更
5. `npm start`
6. ブラウザで `http://localhost:3000` を開く

## Xへの自動投稿を有効にする
1. X Developer Portalで開発者アプリを作成し、投稿権限を設定する
2. ユーザーコンテキストの投稿ができる認証方式を設定し、必要なキーとアクセストークンを取得する
3. `.env` に `X_API_KEY`、`X_API_SECRET`、`X_ACCESS_TOKEN`、`X_ACCESS_TOKEN_SECRET` を設定する
4. 最初は `AUTO_POST=false` のまま、フィード検出とログを確認する
5. 動作・利用規約・費用を確認した後に `AUTO_POST=true` にする
6. サーバーを再起動する

X APIの投稿エンドポイントは `POST https://api.x.com/2/tweets` です。認証情報はブラウザ側に絶対に置かず、`.env` も公開リポジトリにコミットしないでください。

## 設定項目
- `RSS_FEEDS`: RSS/AtomフィードURLをカンマ区切りで指定
- `KEYWORD`: 初期値 `中日ドラゴンズ`
- `CHECK_CRON`: 初期値 `*/5 * * * *`（5分ごと）
- `AUTO_POST`: `false` または `true`
- `MAX_POSTS_PER_CHECK`: 1回のチェックで投稿する最大数（初期値2）

## 安全機能
- 記事URLの重複投稿を防止（ローカルの `state.json` に記録）
- 1回のチェックで投稿する件数に上限
- 投稿OFFが初期設定
- 取得エラー・投稿エラーをダッシュボードに表示

## 次に必要なもの
本番運用には、RSS利用条件を確認したフィードURL、X Developer Portalの認証情報、常時稼働できるホスティング環境が必要です。X APIキーなどの秘密情報をチャットに貼らないでください。
